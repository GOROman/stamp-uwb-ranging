# ハマりどころ

## Channel 5 と Channel 9

製品ページ・ライブラリ既定・GitHub 例は **Channel 9**（中心 7987.2 MHz）。
Arduino ドキュメントのインライン例は `phy.channel = Channel5` 直書きで、シリアル例も `ch=5`。

両端のチャネルが違うと無通信。初回は GitHub 例のまま **Ch9**。ドキュメントの Ch5 例は使わない。

## 番地スキームが公式内で分裂している

| ソース | Tag | Anchor |
|---|---|---|
| GitHub / ドキュメント 2ノード | 0x0001 | 0x0002 |
| ドキュメント §5 マルチ | 0x0001 | 0x0002, 0x0003, 0x0004 |
| GitHub `DS_TWR_MULTI_*` | 0x0001 | 0x0101, 0x0102 |

このリポはドキュメント §5 側（`0x0002` / `0x0003`）を使う。GitHub MULTI の `0x0101` 系とは混ぜない。
PAN は `0xDECA`。

## 接続

- Stamp-S3 / S3A 禁止（ピン非互換、永久破損）
- FPC 逆差し禁止
- FPC を PCB アンテナ下に通さない
- SMT 版（S017）はアンテナをベースボード端からはみ出させる

## DS-TWR と SS-TWR

公式は DS-TWR 推奨。SS-TWR は Tag 側タイムスタンプのみでクロック誤差が大きい。初回は SS を使わない。

## TDoA

製品は「TWR と TDoA に対応」と書いてあるが、現行ライブラリ API は SS-TWR / DS-TWR のみ。TDoA スケッチはない。

## 技適

UWB モジュール（S017 / S017-F）の MIC / 技適は公式認証一覧に見当たらない。チップ Brief は Japan/Korea 対応とあるが、完成品認証ではない。Stamp-C5（S016）は CE/FCC/MIC あり。

## その他

- ライブラリ Arduino 名は `M5Stamp_UWB`（v0.1.1）。`library.json` は 0.1.0 のまま。
- 更新レートは製品仕様に未記載。例は 200 ms 間隔。
- アンテナ遅延はライブラリ既定 16385/16385。公式の基板校正手順なし。
